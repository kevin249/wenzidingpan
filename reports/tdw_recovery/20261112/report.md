# TDW 本地计算输入修复与真实客户端验收

## 原因与修复

TDW 公式和阈值未改变。错误来自输入数据：

1. 分钟历史原先按电脑当前日期过滤。2026-11-12 午夜查看 11 月 11 日行情时，241 根分钟历史被过滤为空，
   只剩 14:44:32 之后的 252 个成交秒采样参与 TDW；价格主图仍有全天分时，导致两者覆盖不一致。
2. 腾讯成交尾页从半分钟开始，原代码却用这些不完整 OHLC 替代已完成的整分钟 K。
   完整分钟参考值为 3.3729462024769585，原收盘后计算值为 3.246455031954225。

现按行情交易日预热；没有成交明细时，非活跃时段允许读取最近可用交易日的真实分钟 K；
进入新交易日活跃时段则拒绝上一交易日数据。收盘后分钟历史覆盖最新成交分钟时，使用完整分钟 OHLC
计算，再映射到显示时间点，不用截断成交尾页替代整分钟。
另修复 UTC 事件标题显示时间，统一转为 Asia/Shanghai，避免 23:46 被显示为 15:46。

## 真实运行客户端验证

用户要求代为启动其已保存 Key、主题 3 的客户端。本机保存的实时地址误指向查询网关 8801，
已通过客户端自身 token 保护的设置 API 修正到 8802，保留 Key、主题与配色。
启动真实 `python -m stockwidget`，修复后重启本任务启动的客户端，保持窗口运行。

从运行中窗口发布的诊断快照确认：

- 交易日：2026-11-11；分钟历史 241 根。
- TDW 有效显示点 475 个，从 09:31 到 15:00:02；显示点包含分钟历史和尾段秒采样映射，不代表 475 根分钟 K。
- 最新动力值 3.3729462024769585；与完整分钟 OHLC 参考计算一致，跨午夜前后误差均为 0。
- 实际窗口和图表可见；千档买 1000 档、卖 598 档，快照校验及绘制回执通过。
- 再次一键测试：连接 37ms、事件回传 327ms、千档采集 506ms、推送快照读取与校验 128ms。
