# 客户端一键测试与千档显示验收

设置页新增「一键测试并显示千档」，使用当前保存的 MCP 地址、实时地址、Key 和第一只自选股。
后台运行并显示阶段结果，不阻塞设置页或 Qt 主线程；显示开关明确打开，沿用现有主题和配色。
调用服务器当前用户专属测试工具，再通过真实订阅读取事件，随后采集真实千档并校验推送快照。
采集到的真实盘口通过 Qt 排队信号交给窗口，绘制回执独立确认；仅收到数据不能报告显示通过。
若事件路径失败仍尝试查询和显示盘口，保留失败阶段；不会以十档代替千档通过测试。

本机链路测试不能外推为远端客户端的公网延迟。

报告不含 Key。截图明确可见图表右侧红绿挂单条。

## 结论边界

用户截图中未见千档，不能仅凭截图确定是开关、连接还是数据问题。
核对后主题 3 默认开启千档；最初把其他主题默认值视为主题 3 的判断已更正。
新版直接报告连接、源数据、快照校验和绘制四层结果，并将手动取得的真实盘口交给窗口，
使后续失败能在客户端直接定位；本次没有宣称公网抖动已根治。
